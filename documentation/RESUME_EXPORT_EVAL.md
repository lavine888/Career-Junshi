# 简历与 LaTeX 导出验收

日期：2026-10-20。范围是将 AI Job Search 的起草、独立内容审阅和 PDF 验收思路
接入军师的岗位版简历流程。上游来源、固定审计版本和 MIT 通知见
[来源说明](ATTRIBUTION.md)。没有引入职位抓取、账户同步、求职信引擎或自动投递。

## 交付与边界

- 宿主负责事实底稿、岗位删留和内容审阅；可用且授权时可派独立审阅者。
- 新增 `resume-export` 入口，依据有来源的结构化数据生成固定单栏模板。
  支持中文 CTeX / Fandol 与英文 article，页数预算为 1 或 2 页。
- 实际导出源码、纯文本、原始内容数据与验收记录；不在安装目录或 Git 仓库内
  生成候选材料，不覆盖现有目录，不启用记忆或上传。
- 可选 `--compile` 使用本机 XeLaTeX。明确请求编译但工具缺失或执行失败时，
  CLI 返回非零，同时保留源码和错误状态；不会把源码当成成功生成的 PDF。
- 编译日志、页数、文字层和视觉审阅分别记录。无日志警告只是 `log_check`，
  不是实际版面验收；源码来源绑定也不是真实经历核验或 ATS 认证。

## 独立前向执行

使用一个新建、不继承实现聊天历史的 subagent，提供 Skill 路径、
[原始合成请求](../cases/experiences/resume-export/request.md) 和指定私有输出目录。
未提供示例输出、结构化样例、预期答案或评分规则；不联网、不读私人材料、
不安装软件、不启用记忆，也不再派生其他 agent。

已检查其实际输出目录：四个源码交付文件均存在，包含中文教育条目和团队原型经历。
正文保留个人方案取舍及验收职责、队友实现服务、原型阶段与离线小样本边界；
没有保留“独立打造服务”或把观测变化归因个人。
来源与等级另存于 JSON，纯文本没有混入 `[SUPPORTED]` 等内部审阅标签。

本机未找到 XeLaTeX。实际尝试请求编译后，验收记录为
`SOURCE_ONLY` / `compilation=UNAVAILABLE` / `pdf_file=null`。
目录中没有 PDF；页数、文字层和视觉检查均未完成。不能将 `page_limit=1`
理解为已经实测一页，也不能以源码块闭合替代编译验证。

该试用的实际导出文件属于隔离的合成验证材料，未混入安装包或公开源码。
公开 `example.md` 是另行编写的教学示意，不计入实际试用。
未单独记录模型版本、采样参数或做重复采样；本次也未验证真实候选人的使用效果。

## 修正与后续验证

集成时发现教育条目允许无 bullet，而早期 helper 要求至少一条，并只在第一条
bullet 后关闭排版块。已支持空列表、修正闭合，并以真实文件生成检查覆盖。
计划标签同时进入文字层预期，防止计划限定丢失；日志检查命名避免冒充视觉检查。

下一项必要的环境验证是在具备 XeLaTeX、CTeX 与 Fandol 的机器上真实编译，
再提取文字并逐页查看。当前不宣称该模板已通过真实 PDF 排版验收，
也不宣称符合所有招聘系统的解析要求。

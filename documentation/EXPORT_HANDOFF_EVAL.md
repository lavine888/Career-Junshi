# 简历导出交付改进

日期：2026-10-20。基线为 [3e81ec1](https://github.com/lavine888/Career-Junshi/commit/3e81ec1751514d5a79216601ff9ab0c3ff8c19d3)。
本轮处理[五个模拟用户试用](MOCK_USER_TRIALS.md)中发现的文件选择摩擦：
导出当轮说明推荐打开哪个文件，以及接下来能做什么。

## 修改范围

- 导出参考按用户目标推荐实际文件：复制或编辑内容用纯文本；明确要修改LaTeX时用源码；
  PDF按实际生成及检查状态交付，编译不可用时说明限制和可用替代。
- 输入JSON、来源与验收记录归为次要查验材料；用户明确要求完整清单时仍完整列出。
- 中英文README在简历导出附近补文件用途表，说明纯文本可复制到Word，不能称为生成了Word文档。
- 本轮没有改变导出器的数据格式、CLI、安装器或长期记忆行为。原五用户试用记录保持原样。

## 复测设计

两份合成请求、已确认的内容JSON和检查项在生成前固定，使用实际安装后的更新Skill。
每位助手从新上下文开始，只获得本例请求、输入和运行资源，看不到检查项、原答复或拟修问题。
一个用户不使用LaTeX，希望预览PDF且保留可编辑结果；另一个熟悉LaTeX，明确只要源码、不编译。

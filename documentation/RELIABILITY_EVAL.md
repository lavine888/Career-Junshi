# 交付可靠性与新上下文试用

日期：2026-10-23。本轮以真实复现的问题为范围，不增加后端、前端或新体验入口。
只使用合成记录、临时目录和临时安装副本，没有读取真人简历或私人项目材料。

## 已补齐的交付边界

| 触发 | 原行为 | 本轮行为 |
| --- | --- | --- |
| 先记录 R3，后补录更早发送的 R2 | 当前附件退回 R2 | 按实际 sent_at 选择最后补交，保留首次投递和全部记录 |
| 两条补交时间是同一真实时刻，但版本不同 | 取后追加记录，掩盖冲突 | 拒绝冲突并要求核实；同版本重复说明可以保留 |
| 旧招聘观察或旧 BLOCKED 回执在后面补录 | 覆盖更新的 Offer / DONE 状态 | 比较 observation at 的真实时刻，保留较新的状态与全部输入历史 |
| next_review_at 传入 null、false、0 等 | 被当成“未约定” | 仅接受带时区时间字符串或空字符串 |
| 准备材料输出指向 Git 或 Skill 目录 | 可能创建含候选人信息的材料 | 写入前拒绝，原文件与目录保持不变 |
| Windows junction 指向包外参考资料 | 校验遗漏，安装会复制包外文件 | 读取目录内容与 catalog 前检查并剪枝，不创建安装目标 |
| 包中出现指向自身的目录联接循环 | 递归可能越过边界或重复遍历 | 在遍历前拒绝链接，保留源与包外文件 |

快照、准备材料、简历和接续导出共用 io_utils 的私有路径检查。保留各调用方原有
覆盖语义：准备材料可用已有私有目录且不覆盖同名文件；简历和接续仍要求全新目录。
Git worktree 的 .git 文件也按仓库边界处理。安装器保留原始路径检查，再 resolve，
防止根路径或祖先的联接被解析后隐去。

附件按 sent_at，招聘和执行观察按事件 at；时区比较使用真实时刻。同一观察时刻按
记录追加顺序处理，真实世界矛盾仍需宿主核对。时间记录不是送达、招聘方采用、
实际执行或职业事实真实性的认证。

## 可重复验证范围

本轮新增 13 个回归函数：6 个接续边界、3 个准备材料边界、4 个安装链接边界。
Windows 上的目录联接测试实际调用 mklink /J，没有用 mock 冒充链接；其他平台
使用实际符号链接。外部 marker、原 Skill 和旧输出在拒绝后保持不变。
部分既有编译失败边界测试仍使用明确标注的模拟工具结果，本轮未重新生成 PDF。

聚焦检查中，动作与接续的 19 项通过；早期路径、打包、接续、快照与简历集合的
54 项通过。完整回归 **275 项通过，143.634 秒**；项目校验与 Skill Creator 基础
校验通过。[实际检查回执](../benchmark/reliability-20261023/verification.json)。
不能把普通机械测试算成自然语言或招聘效果验证。

## 新上下文试用

[实际请求、答复和读取范围](../benchmark/reliability-20261023/forward-trial.md)。

一位未继承根聊天历史的子代理完成两轮合成请求；未提供预期答复、问题定位、
案例或测试。它保留了本人流程判断、AI 实现与同学部署的边界，撤回未经支持的
效果与 AI 示例数字；没有旧练习记录时建立新起点，收到停止后给接续卡。

首轮有一个需要收窄的判断：“没运行验证”可能扩大了示例输出被撤回的范围。
第二轮经用户提醒后改成“没有可核验记录，其他人是否测试未知”。据此补充了开发
复盘指南，要求只撤回依赖失效来源的主张，不抹去仍支持的工作或推断普遍否定。
这是一轮同宿主、同模型设置未单独记录的试用，不是人类独立评审或受控效果实验；
补充的文字指南尚未做第二个新上下文后测。

## 局限

只覆盖本轮的文件系统和记录投影边界；不宣称实现了通用文本真实性判断或完整的
招聘状态机。反馈解释和决策仍需宿主审阅来源。安装源同时被其他进程修改的竞态、
跨机器字体、真实用户耗时及面试／Offer 效果不在本轮验证范围。没有新增安装自动
更新、自动发送材料、公开候选人信息或启用记忆。

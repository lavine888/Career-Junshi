# 三个细节的实现与验证

日期：2026-10-19。本次落实十个候选想法中优先推荐的三项：措辞核对、追问断点续练、
隐藏结果复盘。其余七项未实现。本记录独立于先前的[核心体验验收](EVOLUTION_EVAL.md)。

## 改了什么

- 措辞核对按句子的个人动作、贡献范围、阶段、结果和因果审查，不按动词禁用。
  纠正原简历指南默认要求提供“更强但有风险的句子”的冲突，改为当前可用句和缺证据。
- 暂停守城时给可复制的原问题、原答、缺口和下次单题；恢复依据用户提供的实际记录，
  不靠模型虚构记忆。没有记录时仅补问必要信息。
- 结果揭晓前先冻结面后观察初判，揭晓后追加对照，不回填过去的判断。
  当前上下文已知结果时只做普通复盘，不能靠删除文本恢复盲态。

新参考替换常规 practical，仍保持每次 1–3 份参考；两条新结构化路由只选择参考，
不自动评审、创建报告或保存会话。断点默认留在聊天，不启用长期记忆。
中英文 README 已加入可直接使用的话术与合成示意入口。

评估者不读 example 或评测报告，不联网、不写文件、不启用记忆。

未单独记录模型版本与采样参数，也没有改前改后对照或重复采样。

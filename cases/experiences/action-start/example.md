# 15 分钟的启动卡：编写示意

本文件为人工编写的合成示意，未真实练习、验证记录或测量招聘结果。
输入见 [request.md](request.md)。

先用目前自述收窄一句：

> 在团队文档检索原型中负责需求取舍与一轮验收，服务代码由队友实现；
> 原型未用于生产，验收记录尚待补充。

个人贡献仍是自述；没有把练习当作核验。

| 启动卡 | 本次安排 |
| --- | --- |
| 结果 | 一段能口述的真实贡献说明，外加一个待补证缺口 |
| 触发 | 今晚吃完饭坐回桌前时，先打开这句话，暂不切换模板 |
| 0–3 分钟 | 写出本人做过的一个需求取舍；记不清就写“取舍依据待核对” |
| 3–6 分钟 | 只在已知位置找验收记录，最多 3 分钟；找不到就停止搜索 |
| 6–12 分钟 | 口述一次个人贡献，再检查有没有把队友代码认成自己实现 |
| 12–15 分钟 | 留下一个最关键未知，重复一次窄表述，到时停止 |
| 最小版本 | 没找到材料时，只讲清自己负责什么、队友负责什么、什么仍未知 |

观察点是能否讲清个人动作与边界，不是流利度或录用概率。上述均为待执行安排，
没有声称用户已经练完。若这次仍未开始，下次先核对当时哪里卡住，再缩小一步。

# Career Junshi

Build an independent, installable career decision Skill. Keep SKILL.md small;
load only 1–3 task-relevant references. Preserve evidence, ownership, provenance,
and uncertainty. Do not interpret a passing fixture as a validated career outcome.

Use Python 3.10+ and the standard library for helpers. No backend or frontend.
Run `python -m unittest discover -s tests -v` and
`python scripts/validate_skill.py` before delivery. Synthetic public cases only.
Never read a private vault automatically or commit real candidate materials.
Memory must live outside the installation and require explicit consent.

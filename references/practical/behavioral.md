# Mother story

From a real event, record context, task, the candidate's action, decision, alternative,
team/tool contributions, measured result and limitation. Build a 90-second version
and a longer version grounded in the same facts. Unknown metrics stay unknown.

Practice a failure without inventing redemption: what failed, how it was noticed,
what was changed, and what remains untested. Codex can organize supplied facts;
the user supplies missing experiences. Stop adding polish if the story diverges
from evidence. A follow-up interview is a new observation, not confirmation of causality.

For choosing an event under a new question, use
[interview-coaching](interview-coaching.md) instead of collecting a large new
storybank. Reuse the same facts and source IDs; start with an event cue and opening
sentence before asking for a full narrative.

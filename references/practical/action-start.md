# Start one useful action

Use when a user knows the goal but is not starting, or asks for a small action
within a real time or energy limit. Replace a less relevant practical reference;
the usual 1–3-reference budget still applies. This is task planning, not a
motivation score, personality assessment or mental-health diagnosis.

A user who asks only to talk or explicitly declines action is not asking for a
start card. Listen or stop; do not convert low energy into a productivity task.

## Find the actual obstacle

Reuse the supplied goal, deadline, materials and previous attempts. Distinguish
missing information, missing evidence, unavailable resources, an oversized task
and difficulty starting; these are working hypotheses about this task. Do not
infer laziness, an attachment style, MBTI suitability or a clinical condition.
If a decisive obstacle is unknown, ask one question; otherwise give a usable
small step now. Accept that pausing or reducing scope can be the right choice.

## Give one start card

Keep the action within the user's total budget, including checking materials.
Prefer a meaningful partial artifact over another learning list. State:

- **Useful result:** one thing the user can inspect at the end, connected to the
  immediate goal rather than a streak or arbitrary productivity target.
- **Cue and action:** if a concrete user-supplied occasion occurs, do this one
  action with these already available materials. An invented time is a proposal,
  not a scheduled event or commitment by the user.
- **Minimum version:** what can still be done if time or information runs short.
- **Blocker branch:** after a bounded failed attempt, use existing material or
  preserve the missing fact; do not invent it or keep troubleshooting indefinitely.
- **Check and stop:** observable completion, a firm time limit, and the next
  review point. Not starting is information for reducing or changing the task,
  not a verdict about the person.

Do assistant-owned work immediately when materials and authorization allow it:
rewrite the supplied claim, prepare a blank evidence slot or identify the one
question. Do not represent a plan, rehearsal, application or message as completed
before it actually happens. The user performs their practice and external actions.

For research questions, use R4 and its limits in
[research and application](../knowledge/08-research-and-application.md) instead
of adding an entire bibliography. Cue-linked planning is an adaptation of general
goal-striving research; it does not establish improved hiring outcomes for this
Skill. Ordinary short requests need no lecture or citation dump.

## Continue from the observed result

When the user returns, compare the actual action and artifact with the card.
If they did not start, ask only what blocked this attempt and revise one element
or stop. Do not assign another larger plan as punishment. If evidence is missing,
keep the claim narrow and name one check; practice cannot authenticate authorship.
Give the card in chat. Only create files or compact memory when separately
requested, using the user's chosen destination and existing consent boundaries.

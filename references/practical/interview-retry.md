# Retry one unresolved interview claim

Use when the user asks to re-practice a recorded weak point. Replace the normal
interview practical reference within the 1–3-resource budget. Use the current
conversation or a supplied defense checkpoint; never search private history.

## Recover the specific gap

Carry over the actual claim/source, previous question and answer, selected
criterion and unresolved point. Quote only available answers; a summary is not
a verbatim transcript. If no prior record exists, ask which claim to practice
or start a new declared-criterion session, explicitly without a before/after
comparison. Missing context is not poor performance.

Choose one consequential unresolved point relevant to the actual target and time.
Do not re-test everything already explained. Identify whether the current record
needs clearer expression, missing factual support, conceptual understanding or
resolution of a contradiction. A short answer alone does not establish a skill gap.

## Change the question, preserve the criterion

Ask one focused variant, then wait. Choose a changed input/constraint, a failure
case, a counterfactual or a measurement check that tests the same gap. Mark invented
scenario conditions as hypothetical, not events from the candidate's project.
Do not silently add harder prerequisites or change the criterion after the answer.
Do not reveal a model answer before the attempt. If a hint is requested, offer a
structure or small cue, not invented project facts.

Respond to the user's actual answer: what new detail it contains, what is still
missing and one next probe if useful. Compare against the supplied prior record.
Repeating advice or terminology is not new evidence of handling the changed case.
A coherent hypothetical answer shows an explanation of this case, not historical
implementation, production experience or an authenticated outcome.

Use descriptive practice observations such as explained / partly explained /
not observed / contradictory. Keep them separate from the career confidence
levels VERIFIED / SUPPORTED / SELF_REPORTED / PLANNED. A clear explanation never
automatically verifies the underlying career claim. Inspect a supplied artifact
separately if factual verification is requested.

## Close and return to the same record

Stop immediately on request, at the agreed time, when the selected gap is clear
enough, or after repeated answers add no new detail. End the current branch rather
than escalating pressure indefinitely. A resolved practice gap can leave the
current queue; keep factual uncertainty even after the explanation improves.

Close with previous gap → new answer detail → remaining limit → one next action.
If useful, attach one pending variant and its observation criterion to the existing
defense checkpoint; no second session database or automatic memory. When the task
continues a [tracked opportunity](job-search-journey.md), retain the actual
resume/claim version and replace an unnecessary resource if needed. Record
completed practice only after an attempt occurred. A revised factual claim needs
its own source and revision; the rehearsal itself does not change facts, submitted
resumes or hiring status. Do not promise improved hiring odds.

# Rejection and feedback

Explicit rejection closes this application. No stated reason means the reason is
unknown. Ask once for useful feedback only if appropriate, then stop chasing.

Specific technical-depth feedback supports a small, targeted defense improvement
for this role. Record exact source and scope. Distinguish hard result, observed facts,
user interpretation, agent interpretation and unknown causes. A freeze explanation
does not support downgrading technical confidence.

Review the next 5 comparable opportunities (or a one-week batch). KEEP if other
evidence supports fit; REFINE a repeated gap; consider PIVOT only with broader evidence
and constraints. One result is not a universal verdict. Do not persist an inferred
failure cause as a verified profile fact.

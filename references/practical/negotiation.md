# Negotiation

Retrieve actual written terms, user priorities, alternatives and deadline. Draft a
specific request with an honest reason and a fallback, for example base compensation,
start date or role scope. Do not invent offers, competing salaries or business outcomes.

Separate guaranteed terms from discretionary bonuses and illiquid equity. Unknown
contract or tax effects need current authoritative sources; the Skill is not an
employment-law or investment adviser. Do not calculate unsupported take-home pay.

Codex prepares a draft and comparison; the user sends and negotiates. Observe the
employer's explicit counteroffer. Stop on the user's walk-away condition; only a
human accepts or rejects. Return confirmed terms to the comparison rather than
treating a verbal possibility as an agreed contract.

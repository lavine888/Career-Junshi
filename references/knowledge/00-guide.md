# Knowledge guide

Knowledge explains judgment criteria; Practical turns them into an action.
Read only 1–3 relevant documents per situation. Core engine labels belong in
internal records, not the user's first screen. The routing table is in
[../practical/00-router.md](../practical/00-router.md).

These documents describe methods and adjustable heuristics, not a scientific
prediction of hiring decisions. Distinguish exact observations, interpretations,
unknowns and source freshness. A retrieved note is a lead, not verified evidence.

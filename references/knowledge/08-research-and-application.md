# Career sources: research, guidance and application

Checked 2026-10-20. The first library contains 18 distinct works/documents,
including the original R1–R4. Multiple topics or URLs do not create extra sources.
The JSON cards are the maintained record; the table below is a navigation snapshot.

## Find one useful source

```sh
python scripts/junshi.py sources
python scripts/junshi.py sources --topic interview
python scripts/junshi.py sources --id R7
```

Topic discovery returns bounded summaries in catalog order, not a scientific
ranking. Request one ID for its design/setting, finding, use, limits, jurisdiction,
version and actual reading depth. The command is offline; it does not reopen
papers, establish current law, authenticate candidate claims or prove product benefit.

Use sources for disputed advice, research questions or a decision where the basis
matters. Ordinary rewriting needs no literature lecture. Keep 1–3 relevant
resources: a detailed card counts as one; summary discovery only helps select it.

## Preserve evidence and transfer boundaries

- R1–R4 retain their previous scope: intervention components are not product
  effects; odds are not personal probabilities; online-market writing assistance
  does not test LaTeX; general if–then planning is not a hiring intervention.
- R5 is a career theory, not a personality-to-job classifier. R6 concerns work-fit
  associations, not a validated prediction of this user's fit or success.
- R7–R10 inform interview design; this conversational coach has no demonstrated
  selection validity. R11 memory practice is indirect evidence; R12 does not
  establish that every feedback intervention improves performance.
- R13–R14 concern specific negotiation experiments, not guaranteed salary gains
  or a reason to impose gender/personality stereotypes.
- R15–R18 are version- and jurisdiction-specific official/legal starting points.
  Recheck current authoritative material and applicability before case-specific
  legal conclusions. Consent is not the only possible legal basis for data use.

Distinguish the source's findings from this product's adaptations. A synthesis
of associations is not a causal experiment; an official guide is not an experiment.
A bibliographic record is not a read paper. Reopen the primary passage for new
claims beyond the recorded depth; name access limits instead of filling gaps.
Current jobs, salaries, employer rules and local conditions need fresh sources.

A compact basis card is enough when needed:

`Advice | Source ID/link/version | Design/setting | Read depth |
Finding | Transfer limit | Product adaptation | Next observation`

Keep candidate facts, self-reports and missing proof separate. Do not infer career
fit from personality labels or unrelated relationship research. Software checks
and synthetic conversations do not establish real hiring outcomes.

# Offer evaluation

Ask for the user's goal and hard constraints before ranking offers. Evaluate learning,
ownership, manager, team, career direction / emerging exposure, technical depth,
brand / signaling, optionality, compensation, location, lifestyle and downside.
The user determines weights. A brand name is not a score.

Use observed terms, written documents and attributed reports. Distinguish salary,
bonus assumptions, equity liquidity and cost of living; do not invent take-home pay.
Verify current legal / financial specifics when necessary. Unknown manager quality
or team scope must trigger a concrete question, not an average score.

An optional structured comparison uses 0–5 candidate-supplied ratings and named
nonnegative weights. Show sensitivity: which uncertain dimension can reverse the
preference? A score is preference arithmetic, not objective career value. If ratings,
goals or hard constraints are missing, recommend clarifying those before acceptance.
Only the user can accept or reject an offer.

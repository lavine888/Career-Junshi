Synthetic only, 2026-10-21. One subagent, two sequential user turns, inherited host
model configuration; exact model revision/sampling settings not separately exposed.
The agent was allowed SKILL.md and at most three relevant resources, no tests,
examples, benchmarks, README or implementation findings. It reported reading
job-search-journey, decision intelligence and evidence-and-claims references.

The user targets AI product internships. The prior resume says independently built
a customer-service Agent service; the correction is a team prototype where the user
owned acceptance criteria and scope, while teammates implemented the service.
R1 was reportedly submitted to Synthetic Company A on 2026-10-19 10:00 Asia/Shanghai.
The user asks for wording, treatment of that submitted version, next steps and a
continuation card, with no file writes.

Observed response excerpts:

> 参与团队客服 Agent 原型项目，负责需求范围界定与验收清单制定；服务实现由团队同事负责。

> 不能把它改记成已投 R2。当前尚未查看或修改简历文件，R2 只是拟定版本。

The response kept SELF_REPORTED, gave a conditional correction draft for the user
to send, and recorded missing evidence and no generated/checked PDF in the card.
It reported only read operations, no files, memory or external actions.

## Turn 2 request

The user reports R2 PDF completed and sent via the original recruiting email at
2026-10-21 14:00 Asia/Shanghai. HR reportedly replies at 15:00 that the role is frozen,
without an ability assessment. The user asks whether to change direction or rewrite

Observed response excerpts:

> 现在不需要换方向，也不需要因为这次冻结再改一轮简历。

> 属于同一招聘流程的材料更新，不新增一次初始投递。

> HR 的回复也不能证明其已审阅 R2。

The updated card distinguished original R1, reported R2 update, uninspected PDF,
recruiting freeze and the next local action. No R3 was invented. The agent reported
no new reads, tools, file writes, memory or external actions in this turn.

## Limits

These are excerpts from actual subagent responses, not hand-written ideal examples.
One trial is not broad behavioral validation. Side-effect claims are agent reports,
not independent authentication; all user statements are synthetic and no real-world
recruiting result or adoption was observed.

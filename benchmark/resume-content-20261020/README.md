# 简历内容前向试用

输入为公开合成材料，未使用真人简历。生成前固定 [用户请求](request.md) 与 [验收项](rubric.json)。

两次均从新上下文开始，只读取 AGENTS、SKILL、请求和自行选择的最多三份参考；未提供评审标准、拟修问题或期望答案。

- [首次实际答复](response-before-routing-fix.md)：已有安全草稿和修改理由；普通改简历请求只读共用简历参考，未触达当时仅在导出参考中的完整对照指导。
- 修正：将原句／改写／理由／待确认事实及岗位取舍指导移入共用 `resume.md`，由导出参考链接复用。
- [修正后实际答复](response-after-routing-fix.md)：逐条对照准确原句，保留个人分工及样例边界，删除无依据指标，直接交付可用内容。

[语义核对与答复哈希](review.json)。未使用标题或关键词匹配来代替语义评审。
同请求的两次单次合成试用不构成受控因果比较，也不证明真人采纳、长期稳定性或录用效果。
